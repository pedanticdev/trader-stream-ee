Cluster Mode Required
The comparison dashboard requires running in cluster mode with two TradeStreamEE instances. Please start the comparison environment to see C4 vs G1GC side-by-side.
To start cluster mode:
  1. Open a terminal in the project directory
  2. Run ./start-comparison.sh all or ./demo-quick-start.sh all
  3. Wait for both clusters to start (30-60 seconds)
  4. Refresh this page
Or visit the single-cluster dashboard to monitor a single instance.
